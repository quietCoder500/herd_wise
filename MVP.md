This website will allow for any user to create a farm, create a herd within a farm, and add animals to the farm. For each of those animals and herds, the farmer can attach a record with the data structure defined by the farmer from a record schema. 
- As a farmer, I can sign up and login.
- As a farmer, I can create farms, herds, and animals.
- As a farmer, I can define custom forms for records.
- As a farmer, I can attach records to the animals I created based on my custom forms.
- As a farmer, I can search my entire farm and view each group, animal, and record in it.

## My MVP will be done when:
- [ ] all of the above is possible when starting from the index page
- [ ] each page has the minimum style to look acceptable
